A frontend for the API located at https://github.com/thetruesaftblandaren/RecipeBackend. Should allow users to be able to generate a random link based on what's received from the backend. Users can click the filter checkbox to remove links that aren't guaranteed to be recipes. Note that this is a first draft rather just to check that the backend actually works rather than something complete. Visuals should be updated to allow for a more user friendly experience.
